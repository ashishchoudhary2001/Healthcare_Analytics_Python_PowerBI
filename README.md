# Healthcare Analytics | Python + Power BI

## 📌 Project Overview

This project analyzes healthcare data to identify patterns in patient demographics, medical conditions, hospital operations, billing, insurance coverage, and healthcare outcomes.

The project combines **Python-based Exploratory Data Analysis (EDA)** with an interactive **Power BI dashboard** to transform raw healthcare data into meaningful business insights.

The objective is to demonstrate an end-to-end data analytics workflow:

**Raw Data → Data Cleaning → Exploratory Analysis → KPI Analysis → Visualization → Business Insights**

---

## 🎯 Business Objective

Healthcare organizations generate large amounts of operational and patient-related data. Analyzing this information can help management understand:

- Patient demographics and population characteristics
- Distribution of medical conditions
- Hospital and healthcare service utilization
- Billing and insurance patterns
- Patient admission and discharge trends
- Relationship between healthcare factors
- Areas requiring operational attention
- Key performance indicators for management decision-making
